# הערכת כיסוי ועלות — מדגם דירוגים בישראל (לפני API בתשלום בכלי)

## עקרון

הכלי החינמי מציג **הזדמנויות מהסריקה** (כותרות, מבנה חנות, קישורים) — **לא** מיקום או דירוג בגוגל. לפני חיבור API בתשלום, צריך להבין עלות **למספר בדיקות חודשי צפוי**, לא רק טווח גס.

מחירון API משתנה; להלן **סדר גודל** לתכנון (USD, לפני מע״מ), לפי [מודל קרדיטים](https://dataforseo.com/pricing) טיפוסי:

| בדיקות חודש | קריאות API משוערות | עלות גלמית משוערת | ₪ בערך (3.7) |
|-------------|---------------------|-------------------|--------------|
| **40 דוחות** | ~40 × (30 kw volume + 10 SERP live) ≈ 1,600 יחידות | **$35–55** | 130–200 ₪ |
| **80 דוחות** | ~3,200 יחידות | **$65–95** | 240–350 ₪ |
| **120 דוחות** | ~4,800 יחידות | **$90–140** | 330–520 ₪ |

**לדוח בודד (חנות ישראלית, 30 שאילתות + 10 דפי SERP):** בערך **$0.80–1.40** גלמי (~3–5 ₪) — רק אם מריצים batch ולא סורקים מחדש כל ליד.

פיתוח + QA חד-פעמי בחודש הראשון: **+$40–80** (מיפוי שאילתות עברית, בדיקות על 10 דומיינים).

**מנוי Semrush/Ahrefs מלא ל-MVP הכלי:** בדרך כלל **$300–500+/חודש** קבוע — מתאים לסוכנות, לא ל־«עלות לדוח» בכלי הציבורי.

## דוגמה: מה ספק יכול להחזיר על חנות ישראלית

**אתר:** `shopgarden.co.il` (מבנה `/343xxx-…` קטגוריות, `/items/…` מוצרים — כפי שהסריקה מזהה).

**קלט לשירות הדירוג (ידני או ב-API, אחרי הסריקה החינמית):**

1. דומיין + 8 URLs שנפתחו (קטגוריות + מוצרים מהדוח).
2. רשימת 30 מילות מפתח בעברית, למשל: «ריהוט גן», «שמשייה לגינה», «שולחן גינה אלומיניום», «נדנדה למרפסת»…

**פלט אפשרי מספק (לא מהסריקה החינמית):**

| שדה | דוגמת ערך | שימוש בייעוץ |
|-----|-----------|--------------|
| מיקום ממוצע (דומיין) | «מיקום 28» על שאילתה X | לא מוצג בכלי החינמי |
| URL שמדורג | `/343102-שולחנות-לגינה` או עמוד מוצר `/items/5915070-…` | התאמה לעמודים שכבר נסרקו |
| נפח חיפוש חודשי IL | 1,200 / 90 / — | סדר עדיפויות בשיחה |
| תוצאות SERP (3–5 דומיינים מובילים) | מתחרים מקומיים | הוכחת פער, לא «דירוג ודאי» |
| Featured snippet / Shopping | כן/לא | כיוון תוכן/תמונות |

**מה הכלי כבר נותן בלי ספק:** H1 חסר בבית, 9 קטגוריות + 6 מוצרים במדגם, מסלול בית→קטגוריה→`/items/`, כפתור רכישה במוצרים — זה **בסיס ההמלצה**; דירוג הוא שכבה אופציונלית בתשלום.

## החלטות לפני חיבור בפרודקשן

1. **Rate limit נפרד** מסריקת האתר; דירוג רק בליד מאושר או דוח בתשלום.
2. **Cache 7–14 יום** לפי דומיין — אותו אתר לא יבצע 40 קריאות SERP בחודש.
3. **Copy נעול:** «אין דירוג בבדיקה החינמית» (כבר ב-`formBodyPromote`).
4. **מדד הצלחה לפיילוט:** 15 חנויות IL — האם עלות גלמית ≤ 4 ₪ לדוח ו-90% מהשאילתות רלוונטיות בעברית.
