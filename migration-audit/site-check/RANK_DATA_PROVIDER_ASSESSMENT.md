# הערכת כיסוי ועלות — מדגם דירוגים בישראל (לפני API בתשלום בכלי)

## מטרה

לפני חיבור שירות דירוגים בתשלום ל־«בדיקת אתר», לאפשר לבעל העסק להבין **אילו עמודים לקדם קודם** רק מהסריקה (כותרות, מבנה, חנות/שירות). דירוג בגוגל **לא** כלול בגרסה הנוכחית — ההמלצות מוצגות כהזדמנויות מהסריקה.

מסמך זה מעריך כיסוי ועלות **למדגם מצומצם** של נתוני דירוג/חיפוש בשוק הישראלי, דרך ספק צד־שלישי.

## מה נדרש מספק (MVP)

| יכולת | שימוש בכלי | הערות |
|--------|------------|--------|
| חיפוש לפי מילות מפתח (IL, Google) | עד 20–50 שאילתות לדוח | Locale `he` / מיקום ישראל |
| URL / דומיין של הלקוח | השוואת נראות מול מתחרים סביב URLs שנסרקו | לא חובה בכל MVP |
| SERP snapshot נקודתי | «לאיזו שאילתה העמוד הקרוב ביותר» | לא זמן אמת מלא |
| מגבלות שימוש | התאמה לתקציב — בלי סריקה אוטומטית לכל מבקרי האתר | Batch / cache |

## ספקים נפוצים (לא אימוץ — להשוואה)

### DataForSEO

- **כיסוי:** Google Search ב־IL דרך API; מודול keyword / SERP.
- **מודל עלות:** Pay-as-you-go (קרדיטים לפי קריאה); מינימום תשלום חודשי נמוך יחסית לסטארטאפ.
- **הערכה למדגם:** ~$50–150 לחודש לפיתוח + בדיקות פנימיות (מאות עד כמה אלפי קריאות SERP/מילות מפתח), לפני תנועת לקוחות.
- **יתרון:** גמיש, מתאים ל־cache ול־backfill.
- **חיסרון:** מיפוי שאילתות עברית ואיכות intent דורש הנדסה.

### Semrush / Ahrefs (API או יצוא)

- **כיסוי:** טוב לדומיין ומילות מפתח גלובליות; IL תלוי תוכנית ומיקום.
- **מודל עלות:** מנוי פר סיט (מאות $ לחודש) + מגבלות API.
- **הערכה למדגם:** לרוב **יקר מדי** לשלב MVP של כלי חינמי; מתאים יותר לשירות ייעוץ ידני.
- **יתרון:** UX מוכר לסוכנות.
- **חיסרון:** פחות מתאים לעלות-לקריאה per lead.

### SerpApi / ValueSERP ודומים

- **כיסוי:** SERP live לפי מיקום.
- **מודel:** תשלום לפי חיפוש.
- **הערכה למדגם:** ~$30–100 לחודש לפי volumen בדיקות.
- **יתרון:** פשוט ל־SERP בלבד.
- **חיסרון:** אין ניהול מילות מפתח מתמשך בלי שכבה נוספת.

## המלצת שלב לפני חיבור בפרודקשן

1. **פיילוט ידני (10–15 אתרים ישראלים):** יצוא CSV מספק אחד (DataForSEO או מנוי קיים של הסוכנות) — 30 שאילתות לאתר, השוואה ל־URLs מהסריקה.
2. **מדד הצלחה:** האם אפשר לדעת «3 עמודים + 3 שאילתות» ב־< 5 ₪ עלות גלמית לדוח?
3. **Cache:** תוצאות SERP ל־7–14 יום לכל דומיין — לא לרענן בכל סריקת מבקר.
4. **UX:** בכלי — משפט ברור: דירוגים הם **ייעוץ משלים** / דוח בתשלום, לא חלק מהסריקה החינמית.

## סיכום עלות (גס)

| שלב | עלות חודשית משוערת | הערה |
|-----|---------------------|------|
| פיתוח + QA מדגם | $50–150 | API בלבד, ללא תנועת משתמשים |
| עם cache ו־50 דוחות/חודש | +$20–80 | תלוי עומק SERP |
| מנוי enterprise (Semrush וכו') | $400+ | לא מומלץ ל־MVP הכלי |
